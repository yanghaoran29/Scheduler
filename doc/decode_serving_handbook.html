4. Capture 样例与 SPMD

现行逻辑 SPMD，与 Scheduler capture 样例一致。设计样例基于 pypto-lib main 3ac8fd8815402a0dc17914dc8c9440d9de5b7329（3ac8fd8，Add: DeepSeek V4 MTP CP chunk prefill and prefix cache (#1203)）。

  • 粒度：每个逻辑 dispatch 一节点，外加可选 barrier_dummy；宽度写入 total_spmd_cnt（非 SPMD 为 0）；total_type∈{0..5}（3–5 为 *_SPMD）。
  • 任务数量写法：单任务 a；SPMD m×SPMD(n)（n 为该节点 SPMD 子任务数）。
  • Qwen out / gate / up：每窗收成等宽包——out 5×SPMD(10)，gate/up 5×SPMD(17)；HT 多窗直接写成 25×SPMD(…)；包间无边。
  • 依赖：在逻辑节点上分类边（broadcast / gather / diagonal / bucket / barrier）；包内并行由 spmd_cnt 表达。
